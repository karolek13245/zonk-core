Two personalities

A private assistant. A mini cloud. One app.

Zonk-Core works alone on your phone, or opens up and answers requests from anyone with your server address — you choose which, any time.

📱

Run on device

Chat entirely offline with a model stored on your phone. Private by default, airplane-mode friendly, and free to run forever.

  • Fully offline after a one-time Wi-Fi download
  • Only shows model sizes your phone's memory can run
  • Switch between 1.5B, 3B, and 7B in one tap
  • Apache 2.0 and community licenses — no subscription

Host for others

How hosting works

Three steps to your own endpoint.

01

Point it at your server

Add your server URL and key in Settings, and name the cloud model if you're using one.

02

Flip "Run on device"

Choose the local model that will power replies while it's hosting.

03

Press Start

The phone goes live. Guardrails watch battery, heat, and Wi-Fi the whole time.
